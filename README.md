IT Project Profitability & Resource Utilization Dashboard
 
Project Overview
 
This project is an interactive Power BI dashboard designed to analyze IT project profitability, employee resource utilization, project costs, revenue, and overall business performance.
 
Tools & Technologies
 
- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Excel
- Data Modeling
 
Business Objectives
 
- Analyze project profitability.
- Monitor employee resource utilization.
- Compare project revenue and costs.
- Identify profitable and underperforming projects.
- Support data-driven business decisions.
 
Dashboard Pages
 
1. Project Overview
2. Profitability Analysis
3. Resource Utilization Analysis
 
Repository Structure
 
- Dataset: Original project datasets.
- Screenshots: Dashboard screenshots.
- Documentation: Project report and presentation.
- PBIX: Power BI project file.
 
How to Use
 
1. Download the PBIX file.
2. Open it using Power BI Desktop.
3. If required, update the dataset file paths.
4. Refresh the data to explore the dashboard.
